# ۱۳. امنیت، مالک و تلگرام

[فهرست](README.md)

## چک‌لیست پایه

- رمز یکتا و قوی؛ حذف initial password از محیط بعد از setup موفق.
- TLS معتبر؛ public portهای 8000، 8001 و 62050 باز نباشند.
- API key با کمترین مجوز و تاریخ انقضا؛ حساب نماینده نقش مالک نگیرد.
- بکاپ رمزگذاری‌شده خارج سرور و تمرین بازیابی.
- اصل مجوزها و سورس در دسترس؛ کد پایه را به‌نام ساخت مستقل معرفی نکن.
- آپدیت خودکار بدون staging فعال نیست؛ image pin، release notes و تست را حفظ کن.

مخفی‌کردن URL جای احراز هویت نیست. rate limit فعلی پشت reverse proxy بر IP بلافصل تکیه می‌کند؛ برای مقیاس بالا trusted proxy و IP واقعی را صریح طراحی کن، نه اعتماد به هر X-Forwarded-For ارسالی کاربر.

## بازیابی رمز مالک

اگر SSH/کنسول سرور را مجاز در اختیار داری:

```sh
docker compose -f compose.yaml -f compose.vps.yaml exec panel   python pasarguard-cli.py generate-temp-key
```

نام فرمان داخلی برای سازگاری پایه حفظ شده است. ابزار یک **کلید محرمانهٔ یک‌بارمصرف با اعتبار کوتاه** در ترمینال خودت نشان می‌دهد؛ آن را در چت، log، screenshot یا GitHub نفرست. در صفحهٔ ورود Owner access / دسترسی مالک، حالت Reset را انتخاب، کلید و رمز جدید را وارد کن. گزینهٔ Delete حساب مالک برای بازیابی عادی نیست.

اگر CLI خطا داد، اول Volume، دیتابیس و نسخه را بررسی کن؛ رمز را مستقیم در دیتابیس با تابع hash دستکاری نکن. بعد از reset، نشست‌ها/API keyهای مرتبط و دسترسی‌ها را بازبینی کن.

## کلیدها و گواهی نود

کلید API و TLS نود روی Volume خصوصی قرار دارند. برنامهٔ تمدید گواهی داخلی لازم است؛ نسخهٔ فعلی آن را ۳۶۵روزه می‌سازد و تجدید خودکار کامل هنوز ندارد. برای rotation باید CA ثبت‌شده در پنل و کلید/گواهی نود هماهنگ عوض شوند؛ فقط حذف cert.pem راه درست نیست. در بکاپ نگه دار و پیش از انقضا هشدار عملیاتی تنظیم کن.

## @SAHEBKARAMI با ربات فرق دارد

این ID لینک پشتیبانی است، **توکن ربات نیست**. برای اعلان‌های خودکار:

۱. از BotFather رسمی ربات خودت را بساز.
۲. توکن را فقط در تنظیمات امن پنل/میزبان قرار بده، نه فایل عمومی.
۳. شناسهٔ عددی chat/admin مقصد را طبق مستندات پایه ثبت کن؛ username لزوماً chat ID نیست.
۴. بات را start کن و دسترسی گروه/چت را بررسی کن.
۵. اعلان آزمایشی بدون اسرار بفرست، سپس انواع اعلان را محدود انتخاب کن.

ربات و پرداخت/تمدید خودکار در این انتشار از طرف ما فعال نشده‌اند. token لو رفت؟ revoke/rotate، پاک‌کردن history لازم و بازبینی رخدادها؛ حذف پیام به‌تنهایی کافی نیست.
