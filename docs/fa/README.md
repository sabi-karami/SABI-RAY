## قبل از اجرای دستورها

- `panel.example.com` و `direct.example.com` نمونه‌اند؛ دامنه‌های خودت را جایگزین کن. هیچ رمز پیش‌فرض قابل استفاده‌ای نداریم.
- فرمان‌های Compose از ریشهٔ همین مخزن اجرا می‌شوند. دستور قدیمی `docker-compose.yml` مربوط به پایه است؛ این راهنما از `compose.yaml` استفاده می‌کند.
- برای روش VPS در همهٔ دستورها هر دو فایل `-f compose.yaml -f compose.vps.yaml` را حفظ کن؛ اگر پروتکل مستقیم فعال است فایل سوم `-f compose.direct.yaml` هم لازم است.
- از فرمان `docker compose config` بدون `--quiet` برای گزارش عمومی استفاده نکن: ممکن است اسرار محیطی را چاپ کند.
- این نرم‌افزار آلفاست. بکاپ، تست و مجازبودن استفاده نزد میزبان ضروری‌اند. فهرست قابلیت، گواهِ تست موفق آن روی اینترنت تو نیست.
- [گزارش دقیق تست‌ها](../BUILD-REPORT.md) و [مجوزها](../../NOTICE.md) را بخوان.
